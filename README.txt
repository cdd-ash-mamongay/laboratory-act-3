## How to run
Use a local development server because the project uses JavaScript ES modules.

### VS Code
1. Open the `student-performance-dashboard` folder.
2. Install/use Live Server.
3. Open `index.html` with Live Server.

### Python
From the project folder, run:
`python -m http.server 8000`

Then open:
`http://localhost:8000`
